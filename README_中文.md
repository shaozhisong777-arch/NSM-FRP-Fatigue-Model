# NSM抗剪疲劳模型：中文重组版

本版包含13个MATLAB文件；保留原20文件和23个参考文件供追溯。不是已标定的抗剪疲劳寿命预测工具。

## 快速运行

1. 将code文件夹单独加入MATLAB路径，不与旧cc19或23个参考文件混放。
2. 修改parameters.m中的物理参数；kind默认strip。Q_max/Q_min为总荷载，使用N而非kN。
3. 运行report=verify_model()检查当前算法；它不会替代试验验证。
4. 运行main，或out=run_model('strip')。杆材用out=run_model('rod')。
5. 临时覆盖示例：out=run_model('strip',struct('Q_max',165000,'N_max',100,'plot_on',false));
6. 每个算例使用不同output_dir，避免旧快照文件与本次结果混淆；MAT结果的out.snapshots是本次快照的权威列表。
7. 比较算法或标定结果时固定参数、网格、循环步长、搜索域与软件版本，并保留生成的MAT与CSV。

## 文件职责

- **main.m**：主驱动。选择条材或杆材，指定临时覆盖值，调用统一入口。
- **parameters.m**：公共参数。按几何、FRP、黏结、箍筋、混凝土、疲劳和求解控制分组定义参数。
- **run_model.m**：统一入口。加载配置与几何，调用疲劳计算，根据开关绘图和导出。
- **setup_model.m**：校验与相交几何。在本函数作用域运行参数脚本；收集变量、检查覆盖键、建立裂缝与FRP/箍筋真实交点、计算两侧锚固长度。
- **crack_kinematics.m**：裂缝变形协调。按裂缝角度、滑移比和形状函数，由竖向位移q恢复法向张开w和切向滑移v。
- **bond_law.m**：黏结本构。计算最大历史滑移处三段包络及割线刚度；实际卸载应力由求解器以k乘当前滑移得到。
- **bond_strength.m**：黏结疲劳退化。按各锚固节点的局部激活循环数更新峰值强度，并限制不小于残余强度。
- **solve_anchor.m**：双侧锚固平衡。联合求解裂缝两侧锚固；满足两侧轴力相等与裂缝处滑移和等于delta；固定点失败后用带线搜索的Newton求解。
- **section_response.m**：给定位移的抗剪响应。计算混凝土经验闭合响应、相交箍筋应力、各NSM锚固力与其竖向投影，检查局部失效。
- **solve_equilibrium.m**：整梁剪力平衡。扫描允许裂缝位移范围，寻找上升支变号区间，再二分满足目标剪力；冻结历史进行试算。
- **fatigue_run.m**：循环计算与记忆。先解峰谷荷载，再激活局部节点、推进损伤、重新平衡；位移变化过快或失衡时减小循环块。
- **save_results.m**：导出与绘图。导出完整结果、16列历史、相交位置、各快照场及状态说明；绘制剪力分担和裂缝位移。
- **verify_model.m**：独立验证。检查锚固解析解、网格收敛、强化对照、零幅不退化、局部激活、单筋失效后重平衡、Miner接口、重复调用、步长及导出。

GNU Octave 10.3.0；尚未在商业MATLAB中执行。默认算例完成10000次（503行历史），状态runout_at_Nmax，最大整梁残差0.0497367 N，最大局部力差约1.70e-10 N。条/杆、零幅不退化、局部计数、单筋退出后重平衡、可选Miner、网格/步长、MAT/CSV及PNG路径均实际执行。短程算例重组前后历史最大差0。

## 必须区分的理论来源

**论文一：2022，非2019**

Chen et al., FRP Shear-Strengthened RC Beams: Re-examining the Shear-Crack Effect. J. Compos. Constr. 26(5):04022065. DOI 10.1061/(ASCE)CC.1943-5614.0001251。PDF第8–9页式(9a)–(9d)按裂缝交点应力分解Vs、Vf和Vc；第13–14页讨论裂缝形态及并非所有箍筋均屈服。用于本代码的离散交点、箍筋弹塑性与剪力分担原则，不提供本模型的疲劳寿命公式。

**论文二：2024，ECC-FRP体系**

Chen et al., Shear Resisting Mechanisms of ECC FRP Strengthened RC Beams. J. Compos. Constr. 28(5):04024038. DOI 10.1061/JCCOF2.CCENG-4395。PDF第8–10页式(1)–(5)给出V=Vc+Vs+Vef及覆盖层沿裂缝法向/切向应力的竖向投影；第11页指出张开与滑移相互作用和预裂缝带来的误差。本版仍以用户原始NSM条/杆为对象，不把ECC连续覆盖层公式直接套到离散NSM上。

**本模型的力平衡**

对称四点加载，Q为两个加载点的总荷载，剪跨Vtarget=Q/2。求解Vc(q,Dc)+ΣAsi·min(Es·εsi,fy)+nfaces·ΣTj·sin(αj)=Vtarget。只统计真正穿过临界裂缝的筋。stir_area是单道箍筋有效腿面积总和；nsm_faces只对单面NSM线的竖向分力乘一次。论文一的竖向FRP是该投影在α=90°时的特例。

**裂缝变形与FRP协调**

设r=v/w，g(y)=(1-y/hc)^m，竖向位移q=(cosθ+r sinθ)w，故w=q/(cosθ+r sinθ)、v=r w。第j根NSM沿轴向的裂缝位移为δj=q·g(yj)·[sin(θ+αj)-r cos(θ+αj)]/(cosθ+r sinθ)。该几何投影由本代码坐标与运动学假设推得，并非宣称论文给出了这些闭合表达式。q、w、v均非梁跨中挠度。

**双侧有限锚固**

每侧从裂缝向锚固末端取x，满足dT/dx=−u_f τ、ds/dx=−T/(Ef Af)；两侧自由末端T(L)=0，裂缝处T1(0)=T2(0)，s1(0)+s2(0)=δ。两侧长度分别由真实交点计算；不能只按较短侧任意截断另一侧。求解器输出力差和协调残差；线弹性解析基准为Ki=Ef Af λ tanh(λLi)，T=δ/(1/K1+1/K2)，λ²=u_f τ0/(δm Ef Af)。

**黏结分段与卸载**

包络：s≤δm时τ=τm·s/δm；δm<s≤δu时τ=τr+(τm−τr)(δu−s)/(δu−δm)；s>δu时τ=τr。历史最大滑移决定割线刚度，卸载按该割线回到原点。本版不是具有残余滑移和捏拢效应的完整滞回模型。当某一锚固侧末端历史滑移达到δu，沿用原代码将该根NSM完全退出受力；这是附加失效规则，不能误解为残余段自动等于零。

**混凝土和箍筋的闭合假设**

力平衡本身不足以唯一预测q，需要材料/运动学闭合。沿用Vc=A·(1−exp(−q/q0))·[ρ+(1−ρ)exp(−w/w0)]·(1−Dc)，其中A=con_V_peak并非实际曲线峰值；q0、w0单位为mm。箍筋εsi=q·g(yi)/steel_trans_len。上述关系、线性裂缝形状、r、传递长度均为用户原模型假设，需要试验标定；两篇论文主要从实测应变反算Vc，未提供这条Vc预测公式。

**疲劳推进：借鉴但不照搬抗弯**

保留参考代码的局部计数思路与τm=max[τr,τ0(1−k log10(max(nlocal,1)))]。节点在最大历史滑移超过act_ratio·δm且峰谷滑移幅大于cyclic_slip_tol时激活；激活后只要幅值仍超阈值就继续累积局部循环数。此式目前仅通过激活门槛体现荷载幅影响，不含连续的幅值/均值/频率效应。0.1965、0.75/0.70只是继承默认值，必须用抗剪疲劳数据重新识别；cycle_step是数值步长，不是参考中的foc频率，也不引入挠度经验倍数。

**平衡层级的范围**

本版求解剪跨竖向剪力平衡与NSM锚固轴向平衡，没有独立建立压区和纵筋截面的完整水平力、弯矩平衡。moment_limit只接受用户提供的抗弯上限，不是截面抗弯分析。因而这是受闭合假设约束的临界裂缝抗剪模型，不是完整梁有限元模型。

**可选S-N与失效解释**

钢筋：Nf=Nref(Δσref/Δσ)^m，D+=ΔN/Nf，Δσ取实际相交箍筋峰谷应力范围。混凝土可选接口以峰谷q区间的Vc包络差除以con_width·steel_depth作为等效应力范围。两者默认Nref=Inf关闭，不自动推断材料S-N。单根脱黏/拉断/保护层限值触发后退出，该梁仍须重平衡；数值不收敛不等于物理破坏。无根仅表示指定q域内未找到允许上升支；采样承载曲线不是精确全局极值。

## 发现与处理

- 原20文件中的cc19_shearforce与cc19_paper_interpolation完全重复，现合并为fatigue_run内的truss_reference，仅作对照，不参与真实离散力平衡。
- cc19_load在原求解主链中未使用，现删除独立文件；对称四点加载的Q/2与剪跨抗弯上限检查保留在平衡逻辑中。
- ff19调用的cc19_plot未提供，已实现为save_results内的plot_history。原导出依赖的codeVersion、sourceNotes字段缺失，已在setup_model补齐。
- 原裂缝角注释将57.1−12.84(a/h)标为“2019式2a”，与所附2022论文的式(2a)不符。现保留原默认数值28.21°，明确是待观测/标定值，修改几何时应重新给定角度。
- VcPeak原注释为kN，但程序力单位是N；已修正为60000 N。混凝土增长和软化尺度单位为mm，不再笼统称为系数。
- 数值核心保留有限锚固、不可逆记忆、峰谷平衡和自适应循环块；合并文件并非将软化问题改成抗弯的Pe/Ps线性插值。新增测试和中文说明，总代码行数不以强行缩减为目标。
- 参数定义没有p.，其余函数使用cfg传递配置，避免global、assignin和依赖调用者工作区。setup_model中的eval仅读取who列出的本地变量名，不执行用户输入字符串。
