# anchorage.m：双侧锚固求解的新手说明

本文件由本次上传的 cc19_hard.m 改写，保持原公式、输入输出和破坏判断。文件名和主函数名均改为 anchorage。参数仍通过 p 结构传入，代码注释使用英文。内部三个辅助函数放在同一个文件，不增加模型模块数。

## 需要替换的文件

下载根目录 anchorage.m 和 trial.m。trial 中原来的 cc19_hard(...) 已改为 anchorage(...)。其余尚未改名的依赖继续使用 code20 版本。根目录应优先于 code20 位于 MATLAB 路径中。历史 code20、original_20 中的原文件保留用于对比；旧入口不会自动切换到新函数。

## 主函数的步骤

1. 读取两侧网格，用 for 循环建立局部节点与整体节点的对应编号。两侧共用裂缝处的节点。
2. 用 for 循环逐个加入杆单元刚度。每个单元的轴向刚度为 Ef*Af/单元长度；对角项加刚度，相邻节点项为负刚度。
3. 重复更新节点滑移、历史最大滑移及黏结割线刚度。用节点循环累加整体矩阵和右端项，求出新的位移。
4. 如果上述迭代没有收敛，使用原来的 Newton 备用迭代；保留四个初值以及缩短步长的循环。
5. 计算两侧黏结应力和轴力，检查收敛与完整脱黏状态，然后逐个字段写入结果。

## 循环怎样读

```matlab
for node = 1:n + 1
    left = leftIndex(node);
    bondDiagonal(left) = bondDiagonal(left) + c1(node);
end
```

node 从 1 到 n+1，逐个处理这一侧的节点；left 是当前节点在整体矩阵中的编号；最后一行把该节点的黏结刚度累加到对应位置。这代替了原来的 accumarray 写法。

软化区的逻辑索引也换成了逐节点 if 判断：先判断是否加载，再判断是否超过历史最大滑移，最后判断处于软化段还是残余段。输出中复杂的嵌套 struct 构造改为 a.force、a.status 等逐项赋值。

## 保留的 MATLAB 基础运算

- `A \ rhs`：求解线性方程组 A*u=rhs。这是求解所必需的基础运算；不能简单改为逐个相除。
- `sparse(m,m)`：创建稀疏矩阵，避免较细网格占用过多内存。其后按普通二维数组方式赋值。
- `.*`：对应节点的数值相乘，例如黏结刚度乘滑移。
- `hist1(:)`：把输入统一成列向量。
- `cumtrapz`：沿锚固长度累计积分黏结应力，得到轴力分布。

这些简短的基础运算保留；矩阵装配、软化分支等较难理解的组合写法改成循环。循环写法更长，目的在于容易逐行阅读，并不保证运行更快。

## 结果与物理意义

输入 delta 是裂缝两侧锚固端滑移之和，不是梁跨中挠度。两侧轴力应相等；forceResidual 是两侧轴力差的绝对值。force 是两侧轴力的平均值，沿 FRP 筋自身方向。用于抗剪时由 trial 按实际筋角度取竖向分量。

本次保留 dT/dx=-perimeter*tau、du/dx=-T/(Ef*Af)、裂缝处两侧轴力相等及滑移和等于 delta 的计算关系。黏结包络与退化仍由原依赖提供，没有通过语法简化加入新的剪切疲劳理论。

## 验证范围

在 GNU Octave 10.3.0 中与上传原代码逐字段对比：48 项锚固检查涵盖 strip/rod、不同滑移、两侧不同长度、加载/卸载和强制 Newton 回退；另有 25 项 trial/承载路径检查及 11 个短程疲劳工况。上述对比检验代码等价性，不代表模型已通过试验标定。

强制回退的个别工况中新旧代码均出现矩阵奇异警告，输出仍一致；本次没有改变原算法处理这些工况的方式。验证日志与复现脚本见 validation20/anchorage_*。
