# prepare_parameters.m：检查输入并准备几何参数

由本次上传的 cc19_validate.m 改名、简化。保留 function、p 参数结构和原检查及公式，注释改为英文。

## 为什么保留 p.

p 是 MATLAB 的结构体，点号用于读写里面的字段，不是特殊的力学符号，也不是不可缺少的字母。p 是 parameters 的简写，可以把它理解为一张参数表。

```matlab
p.Ef = 150000;
p.Af = 20;
axialStiffness = p.Ef * p.Af;
```

三个表达式分别把数值保存到 Ef、Af 字段，再取出来相乘。p.Ef 与 Ef 是两个不同的变量名称。

保留结构体的好处是其他函数只需要接收一个 p，就可以使用同一套参数和派生几何量，不必传入几十个独立输入。新字段也容易添加。p. 不是必须采用的形式，但若去掉，需要统一修改所有使用它的函数；在一个函数中删除 p. 并不能让这些局部变量自动传给其他函数。

本项目不使用全局变量来共享这些参数。prepare_parameters 的返回值很重要：

```matlab
p = parameters('strip');
p = prepare_parameters(p);
```

第二行接收检查后并添加了派生量的结构体。函数内部添加字段后，调用者需接收返回值才能继续使用这些新增字段。

## 动态字段的含义

参数检查名单保留为 cell 数组，避免重复几十段相同代码：

```matlab
fieldName = pos{k};
v = p.(fieldName);
```

pos{k} 取出第 k 个字段名称，比如 'width'；这时 p.(fieldName) 就等同 p.width。这是动态字段访问，和 p.Ef 属于同一套结构体语法，只是字段名由变量给出。

## 七个部分

1. 按名单循环检查正数、非负数、整数、允许 Inf 的上限，以及开关。
2. 把原来一条很长的综合判断拆成若干较短的 if，检查几何、荷载、角度和黏结参数的相容性。
3. 将角度从度换成弧度，计算裂缝运动分母、筋投影系数与裂缝顶端位置。
4. 按筋循环生成端点表，或读取自定义端点表。
5. 按筋计算裂缝交点、交点两侧的锚固长度、局部形状值和实际筋角度。原来的整行拼接改成逐列赋值。
6. 按箍筋循环挑出穿过裂缝的箍筋，逐列建立 p.steel。
7. 检查输出循环数和路径，用循环筛选不超过 Nmax 的快照循环数。

节点形状的简单数组公式继续保留，以保持与旧版的浮点计算一致。交点求解中的 `A \ rhs` 保留：它是在求解两个几何方程，并不适合替换成逐项相除。unique 用于排序并去除重复快照循环数。

## 新增到 p 的主要字段

- theta、alpha：以弧度表示的角度。
- kinematicDenominator、nsmProjection：原假定裂缝运动中的分母和筋方向投影。
- crackTopX：裂缝顶端横坐标。
- generatedSegments：筋端点表，每行两端点的 x、y。
- bars：真实交点横纵坐标、下侧锚固长度、上侧锚固长度、局部形状值、实际筋角度，共六列。
- nBars：真正穿过裂缝并满足原筛选条件的筋数。
- steel：箍筋交点横坐标、纵坐标和形状值，共三列。
- nSteel：穿过裂缝的箍筋数量。

这部分沿用旧几何算法，没有加入新的抗剪理论。实际竖向筋可以将输入 alphaDeg 设为 90；本次没有替你修改 parameters 中原来的默认角度。
