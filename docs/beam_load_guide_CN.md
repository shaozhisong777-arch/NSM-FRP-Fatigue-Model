# beam_load.m：对称四点加载的弯矩和剪力

由本次上传的 cc19_load.m 改名、简化，保留 function、p 参数结构、原公式和英文注释。当前疲劳主流程没有调用本函数；本次不修改其他计算文件，不额外把它接入主求解链。

## 使用

```matlab
p = parameters('strip');
x = linspace(0, p.span, 101);
[M, V] = beam_load(p, x, p.Qmax);
```

省略第三个输入时，Q 默认为 p.Qmax。x 从左支座起算，单位 mm；Q 单位 N；输出 M 为 N·mm，V 为 N。行向量、列向量和矩阵保持输入形状。

## 荷载定义

Q 是两个加载点的总荷载；对称时每个加载点的力为 Q/2，每个支座反力也为 Q/2。左右加载点分别为 a=p.shearSpan、L-a，其中 L=p.span。该式假定简支、对称四点加载，仅考虑输入 Q 对应的荷载，不自行加入自重。

弯矩原公式：M(x)=Q/2*min(x,L-x,a)。

剪力原分段：左剪跨 x<a 为 +Q/2，两加载点之间为 0，右剪跨 x>L-a 为 -Q/2。

原代码在恰好两个加载点处把 V 记为 0，本次保留。集中力处剪力有跳跃，不能把该单点数值解释为加载点两边的剪力均为零；绘制剪力图时应使用左右极限。支座处也是原数组端点约定。

## 简化的语法

用一个循环检查 x 是否超出梁长；另一个循环逐位置计算。嵌套 min 拆成 momentArm 的两步赋值，剪力的数组逻辑索引改为 if。两个剪力 if 的执行次序保持原样，正常几何由参数准备函数检查。

不改动原输入校验的范围：本文件不是完整的参数检查器，例如未新增 Q 的合法性检查。相应参数仍应由 parameters 和 prepare_parameters 正确设置。
