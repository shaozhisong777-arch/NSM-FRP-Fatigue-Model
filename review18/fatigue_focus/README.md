重点：初始峰谷 → 节点激活 → 局部龄期 → 峰值黏结应力退化 → 候选峰谷重平衡 → 接受、重试或停止。

PPT将整体循环数N、节点局部循环数Ni和循环块ΔN分开解释。条材15.72MPa、Ni从100到120的数值是论文退化式的代入示例，不是试验结果或新整梁模拟。循环块在块起点识别活跃节点，是数值近似；默认箍筋与混凝土S-N关闭，未将其描述为已经实现全部材料的疲劳破坏。
