# 16个代码的作用总结｜Chinese / English
每个文件对应PPT一页，仅总结作用，不展开公式。

## main_drive.m — 主驱动脚本 / Main driver script
设置本次算例并启动整个计算。
Configure a case and start the calculation.

- 选择条材或杆材。
  Select FRP strips or rods.
- 按需覆盖本次运行参数。
  Optionally override parameters for this run.
- 调用统一入口，保留计算结果。
  Call the main entry and retain the results.

## parameters.m — 默认参数 / Default parameters
集中提供模型和计算的默认设置。
Provide the default model and analysis settings.

- 定义几何、材料、黏结和荷载参数。
  Define geometry, materials, bond and loading parameters.
- 设置循环数及数值控制参数。
  Set cycle limits and numerical controls.
- 设置绘图和文件导出选项。
  Set plotting and file-export options.

## read_and_calculate.m — 统一入口 / Calculation entry point
连接参数读取、疲劳计算和结果导出。
Link parameter loading, fatigue analysis and result export.

- 读取默认参数并应用本次覆盖值。
  Load defaults and apply run-specific overrides.
- 调用疲劳计算主函数。
  Call the fatigue analysis controller.
- 根据开关调用绘图与导出。
  Trigger plotting and export when enabled.

## prepare_parameters.m — 参数检查与几何准备 / Parameter checks and geometry
检查输入并建立求解需要的几何信息。
Check inputs and prepare the geometry used by the solver.

- 检查参数范围和相互关系。
  Check parameter ranges and consistency.
- 确定裂缝与FRP筋的真实交点。
  Locate actual crack–FRP intersections.
- 计算两侧锚固长度及穿缝箍筋位置。
  Calculate anchor lengths and intersecting stirrup positions.

## fatigue_calculate.m — 疲劳计算总控制 / Fatigue analysis controller
组织峰谷平衡、损伤更新和循环推进。
Coordinate load-state equilibrium, history updates and cycle progression.

- 初始化历史并求初始峰谷状态。
  Initialize history and solve the initial peak and valley states.
- 提出候选循环块，必要时减半重试。
  Propose cycle blocks and halve them when required.
- 接受有效状态并记录结果和停止原因。
  Accept valid states and record results and stop reasons.

## capacity_scan.m — 初始抗剪响应扫描 / Initial shear-response scan
提供当前历史下的可选静力路径诊断。
Provide an optional static-path diagnostic for the current history.

- 按递增裂缝位移计算抗剪响应。
  Sample shear resistance at increasing crack displacement.
- 保留成功点的加载历史。
  Carry forward successful loading history.
- 记录有效采样峰值与数值失败点。
  Record the sampled peak and numerical failures.

## state.m — 抗剪平衡求解 / Shear-equilibrium solver
寻找满足目标剪力的裂缝竖向位移差。
Find the vertical crack jump that balances the target shear.

- 设置峰值或谷值的搜索范围。
  Set the peak- or valley-state search interval.
- 扫描并二分搜索有效平衡根。
  Scan and bisect to find a valid equilibrium root.
- 返回平衡响应或具体求解诊断。
  Return the balanced response or a specific diagnostic.

## trial.m — 单次抗剪响应计算 / Single trial response
在给定裂缝位移下计算各项抗剪贡献。
Evaluate shear-resistance components at a prescribed crack jump.

- 计算混凝土和箍筋贡献。
  Calculate concrete and stirrup contributions.
- 逐根求FRP锚固响应并检查筋失效。
  Solve each FRP anchor response and check bar failure.
- 汇总FRP竖向力与总抗剪力。
  Sum FRP vertical forces and total shear resistance.

## crack_deformation.m — 裂缝变形分布 / Crack-deformation profiles
由裂缝竖向位移尺度得到指定的变形分布。
Generate prescribed crack profiles from the vertical crack-jump scale.

- 建立沿裂缝高度的形状分布。
  Define the profile along the crack height.
- 计算法向张开和切向滑移。
  Calculate normal opening and tangential sliding.
- 返回竖向、水平位移差及绘图数据。
  Return vertical/horizontal jumps and profile data.

## bond_strength.m — 黏结峰值疲劳退化 / Fatigue degradation of bond peaks
按节点局部循环数计算退化后的黏结峰值。
Calculate degraded peak bond stress from local cycle counts.

- 检查局部循环历史。
  Check the local cycle history.
- 区分杆材和条材的退化系数。
  Use the rod- or strip-specific degradation coefficient.
- 返回非负的节点峰值黏结应力。
  Return nonnegative nodal peak bond stresses.

## anchorage.m — 双侧锚固求解 / Two-sided anchorage solver
求裂缝两侧锚固段的滑移和筋力。
Solve slip and bar force on both sides of the crack.

- 组装杆单元和黏结刚度。
  Assemble bar-element and bond stiffness.
- 迭代满足两侧滑移协调与力平衡。
  Iterate to satisfy slip compatibility and force balance.
- 返回局部应力、应变及脱黏状态。
  Return local stresses, strains and debonding status.

## anchor_mesh.m — 锚固网格 / Anchorage mesh
为一个锚固段建立一维数值离散。
Create a one-dimensional discretization of an anchor segment.

- 按设定单元数生成节点位置。
  Generate nodes using the specified element count.
- 计算各单元长度。
  Calculate element lengths.
- 提供梯形积分的节点权重。
  Provide nodal trapezoidal integration weights.

## bond.m — 黏结本构关系 / Bond constitutive relation
根据历史最大滑移计算黏结包络和刚度。
Evaluate the bond envelope and stiffness from maximum slip history.

- 判断弹性、软化或残余阶段。
  Identify the elastic, softening or residual branch.
- 计算包络应力及割线刚度。
  Calculate envelope stress and secant stiffness.
- 供锚固求解计算当前黏结应力。
  Supply stiffness for current anchor-stress evaluation.

## active_nodes.m — 疲劳活跃节点判断 / Active fatigue-node selection
判断哪些节点可以累计本步疲劳循环。
Identify nodes eligible to accumulate local fatigue cycles.

- 检查滑移阈值和历史激活记录。
  Check the slip threshold and previous activation.
- 检查峰谷滑移差是否超过容差。
  Check that the peak–valley slip range exceeds tolerance.
- 返回活跃标志及滑移差。
  Return active-node flags and slip ranges.

## save_snapshot.m — 计算快照整理 / Response snapshot assembly
整理选定循环数的响应和局部场数据。
Assemble response and local-field data at selected cycle counts.

- 按筋、锚固侧和节点整理局部场。
  Organize fields by bar, anchor side and node.
- 记录箍筋响应及裂缝变形分布。
  Record stirrup responses and crack profiles.
- 返回快照结构体，供后续绘图和导出。
  Return snapshot data for plotting and export.

## export_results.m — 绘图与结果导出 / Plotting and result export
将计算结果转换为图像和可读取的数据文件。
Convert analysis results into figures and readable data files.

- 绘制循环历史、几何和局部场。
  Plot cycle histories, geometry and local profiles.
- 导出MAT、CSV和PNG。
  Export MAT, CSV and PNG files.
- 记录计算状态、残差及失效信息。
  Record analysis status, residuals and failure information.
