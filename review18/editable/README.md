GitHub文件页点击Download raw下载。draw.io文件使用 https://app.diagrams.net/ 打开，选择“文件→从设备打开”，选择下载的.drawio文件。双击框修改文字，拖动框调整位置；箭头可单独选中或重新连接。

PowerPoint版本只有一页，使用标准圆角矩形、文本和直线连接符，没有图片或自定义路径，便于编辑。箭头表示直接调用；beam_load、shearfoce没有接入主链。图中18个文件与本次上传文件一致，17条箭头为实际调用关系。
