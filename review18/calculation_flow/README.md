# 抗剪疲劳的计算流程（区别于文件调用图）

按当前16文件主链组织。用物理量、方程、循环与判断表示计算顺序，并在节点末尾注明对应函数。没有把抗弯原文的临界荷载Ps/Pd、跨中挠度或原文“式13无解”等判断直接搬入抗剪程序。

- [计算主流程PNG](抗剪疲劳计算主流程.png)：初始化、峰谷平衡、活跃节点、候选局部龄期、循环块重试、接受/停止与输出。
- [峰谷平衡内部计算PNG](峰谷抗剪平衡的内部计算.png)：试探q、裂缝运动、材料贡献、双侧锚固、筋失效、力平衡与q调整。
- [可编辑PPT，两页](抗剪疲劳计算流程_可编辑.pptx)：标准形状、文本框和分段连接线；无逻辑图图片。竖向画布，建议放大后编辑。
- [可编辑draw.io，两页](抗剪疲劳计算流程_可编辑.drawio)：在 https://app.diagrams.net/ 中选择“文件→从设备打开”。
- [PDF预览](抗剪疲劳计算流程.pdf)

在GitHub文件页点击Download raw下载。draw.io节点和箭头可移动、重连；PPT绕行箭头由若干独立的标准线段组成，移动节点后可能需要同步调整中间线段。公式是可编辑文本。

判断与代码保持一致：只对候选峰值失败/位移增长过快进行循环块减半；谷值失败则返回诊断。没有活跃节点且可选S–N均关闭时，记录至Nmax并标记runout。q是裂缝竖向位移差，不是梁跨中挠度。无根仅指指定域和分支下的模型诊断，局部数值失败不直接称物理脱黏破坏。

[F19] DOI 10.1016/j.ijfatigue.2019.04.039：局部黏结退化式(2)、阈值背景。
[S19] DOI 10.1061/(ASCE)CC.1943-5614.0000953：双侧协调及应变连续背景；未实现其完整PST/Green式(7)。
[R22] DOI 10.1061/(ASCE)CC.1943-5614.0001251：穿缝筋离散贡献和分量平衡背景。

Vc闭合式、裂缝分布g、滑移比r、箍筋传力长度ls包含代码经验假定；双侧锚固采用数值实现，并非完整照抄原文解析解。新提供的DOI尾号0000446论文不作为本代码FRP界面疲劳退化式的来源。
